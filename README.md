# ivtecture/srs

Репозиторий для домашних заданий по дисциплине (SRS — Software Requirements Specification).

## Правила работы

- Изменения в `main` принимаются **только через Pull Request** из отдельной ветки.
- Прямые push в `main` запрещены (branch protection).
- Для слияния PR требуется обязательное одобрение кодовладельца: **@MarkDvoryanchikov**.
